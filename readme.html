Tabby — Window & Tab Manager

Firefox-first tab management dashboard with visual previews, session recovery, strict bookmark deduplication, and automated video-watch bookmarking.

Firefox First Manifest V3 Webpack 5 Version 3.2.1+

📖 User & Developer Guide

This section outlines how to use the extension's core features as a user, and how to test them as a developer.

USER GUIDE

How to Use Tabby

  • Dashboard Previews: Open a new tab (Ctrl+T) to see the dashboard. You will see auto-generated thumbnail previews of all other open tabs in the window.
  • Restoring Sessions: When you close a window, Tabby saves it. To restore it, open a New Tab, scroll down to the Settings panel (click the gear icon), and under Session history, click Restore on a recent session.
  • Bookmark Cleanup: If your bookmarks get messy, open the Settings panel in the New Tab dashboard, find Bookmark Maintenance, and click Scan Bookmarks. Click Clean Violations to automatically remove true excess duplicates according to the Max 2 rule (preserving up to 1 Core + 1 Date bookmark per URL).
  • Button Hovertext: Hover over any button across the dashboard, toolbar, or settings panel to view explanatory tooltip text detailing what that action does.
  • Watching Video: If you watch a video on a page that is bookmarked in the Next folder, just watch it for at least 10 seconds. Tabby will automatically remove it from the Next folder.
DEVELOPER GUIDE

How to Test Features Locally

  • Testing Session Capture:
    1. Open a new window with a few tabs.
    2. Close the window.
    3. Open another window, open the Tabby dashboard, and verify the session appears in the Settings > Session history list.
  • Testing Auto-Bookmark "Next": Close a window with an unbookmarked URL. Check your bookmarks to ensure it was added to the Next folder.
  • Testing Bookmark Rules: Manually bookmark the same URL in 3 core folders (e.g., New, Previous, S tier). Open the Tabby dashboard, go to Settings > Bookmark Maintenance, and run a scan. It should flag the violation. Click Clean and verify only 1 core bookmark remains.
  • Testing Video Detector: Add a YouTube video to the Next bookmark folder. Open the video, ensure the tab is active, and let it play for >10 seconds. Check your bookmarks; the URL should no longer be in the Next folder.

📦 Project Overview

Tabby transforms the browser's New Tab page into a high-performance visual control surface. Instead of live DOM embeds, Tabby uses cached static screenshots and lightweight tab metadata to provide instant window overview, tab search/filtering, and reordering.

🖼 New Tab Dashboard

Visual preview grid for all other tabs in the current window with drag-and-drop browser order sorting.

💾 Auto Session Capture

Snapshots window state on close and keeps up to 5 recently closed sessions ready for instant restoration.

📑 Bookmark Rules Engine

Enforces a maximum of 1 Core bookmark + 1 Date bookmark per URL, with automated cleanup tools.

🎬 Auto Watch Removal

Detects video playback or active 10s tab viewing and automatically clears matching Next bookmarks.

⚙️ User Preferences & Workflow Rules

The extension strictly follows these curated workflows and user preferences:

WORKFLOW RULE 1

Session Capture on Window Close

When closing an entire browser window:

  • Automatically bookmarks any open, non-bookmarked tab into the Next bookmark folder.
  • Saves full metadata for all tab URLs in extension memory (up to 5 recent sessions).
  • Provides Restore Sessions in the New Tab toolbar for reopening whole windows or single tabs.
WORKFLOW RULE 2

Max 2 Bookmarks Rule (1 Core + 1 Date)

Every bookmarked site/URL is governed by strict categorization:

  • Core Bookmark Folders: S tier, New, Previous, Repeat, Revisit, Next.
  • Date Bookmark Folders/Titles: Contains numbers and periods only (regex ^[0-9.]+$, e.g. 2026.07.19, 12.31).
  • Constraint: No URL can have more than 1 Core bookmark and 1 Date bookmark (maximum 2 bookmarks total). Auto-bookmarking replaces previous core bookmarks to maintain this limit.
WORKFLOW RULE 3

Automated "Next" Bookmark Removal on Video Watch

When watching media saved in the Next bookmark folder:

  • Content scripts listen for HTML5 <video> play/playing events with >3s playback or 10s active tab viewing.
  • Sends a background request to remove the URL from the Next bookmark folder automatically once consumed.
WORKFLOW RULE 4

Bookmark Clean-Up Manager

Integrated tool in the New Tab dashboard for library hygiene:

  • Scans bookmarks for exact URL duplicates, multi-core folder violations, and multi-date violations.
  • Provides one-click Smart Auto-Clean (retains newest core + date bookmark) and granular selection.

🛠 Building & Installation

Build Commands

# Install dependencies
npm install

# Build for Firefox (Primary Target)
npm run build:firefox

# Build for Chrome or generic WebExtension
npm run build:chrome
npm run build:webext

Loading in Firefox

  1. Open about:debugging in Firefox.
  2. Click This Firefox in the sidebar.
  3. Click Load Temporary Add-on...
  4. Select dist/manifest.json from the built project directory.

📂 Codebase Sitemap

  • src/newtab/newtab.js — Dashboard UI, card grid, session history modal, bookmark cleanup manager modal.
  • src/popup/ & src/options/ — Restored legacy popup and global options UI.
